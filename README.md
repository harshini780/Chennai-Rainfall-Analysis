# Chennai Rainfall & Monsoon Insights (1993–2023)

## Project Overview
This project analyses historical rainfall patterns in Chennai from 1993 to 2023 using Tableau.

## Objectives
- Analyse annual rainfall trends.
- Understand monthly rainfall distribution.
- Compare rainfall across monsoon seasons.
- Identify rainfall patterns using a heatmap.
- Present important rainfall statistics through KPI cards.

## Tools Used
- Tableau Public
- Microsoft Excel
- CSV datasets

## Dataset
The project uses historical Chennai rainfall observations, including station-level and citywide daily rainfall data.

The citywide dataset contains 3,383 recorded dates. The records do not cover every calendar date in the study period, so the analysis is based on available observations.

## Dashboard Visualisations
1. Total Rainfall KPI
2. Average Rainfall KPI
3. Highest Daily Rainfall KPI
4. Recorded Dates KPI
5. Annual Rainfall Trend
6. Monthly Rainfall Distribution
7. Monsoon Comparison
8. Rainfall Heatmap

## Project Outcome
An interactive Tableau dashboard that makes historical rainfall patterns easier to explore and understand.
