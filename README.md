# 🌧️ Chennai Rainfall & Monsoon Insights (1993–2023)

An interactive data analytics project that explores historical rainfall patterns in Chennai using Tableau.

![Chennai Rainfall Dashboard](Screenshot%202026-11-13%20082744.png)

## 📌 Project Overview

This project analyses historical rainfall observations in Chennai from 1993 to 2023. The objective is to understand rainfall variations across years, months and monsoon seasons through data analysis and interactive visualisation.

## 🎯 Project Objectives

- Analyse annual rainfall trends.
- Understand monthly rainfall distribution.
- Compare rainfall across monsoon seasons.
- Identify rainfall patterns using a heatmap.
- Present key rainfall statistics through KPI cards.

## 📂 Dataset Description

The project uses historical rainfall datasets containing:

**1. Citywide Daily Rainfall**
- Daily average rainfall observations for Chennai.
- Used for yearly, monthly and seasonal analysis.
- Contains 3,383 recorded dates.

**2. Station-Level Rainfall**
- Rainfall observations from individual stations.
- Supports station-level rainfall analysis.

**3. Additional Analysis Workbook**
- Excel workbook containing supporting project analysis.

**Note:** The available daily observations do not cover every calendar date from 1993 to 2023. Results are therefore based on recorded observations.

## 📊 Dashboard Features

| Visualisation | Purpose |
|---|---|
| Total Rainfall KPI | Displays the sum of recorded rainfall |
| Average Rainfall KPI | Shows average rainfall per recorded date |
| Highest Daily Rainfall KPI | Displays the maximum daily rainfall |
| Recorded Dates KPI | Shows the number of recorded dates |
| Annual Rainfall Trend | Compares rainfall across years |
| Monthly Rainfall Distribution | Compares rainfall across months |
| Monsoon Comparison | Examines seasonal rainfall variations |
| Rainfall Heatmap | Highlights rainfall patterns using colours |

## 🔍 Key Analysis and Insights

- Examines variations in rainfall across different years.
- Compares rainfall distribution across the twelve months.
- Explores differences between monsoon seasons.
- Uses colour intensity to identify higher and lower rainfall periods.
- Summarises important rainfall statistics through KPI cards.
